# Prints do app cliente

Capturas do app cliente rodando no emulador Android, na ordem do fluxo de uso.

1. `01-login.png` — tela de login.
2. `02-login-erro.png` — login com senha errada (mensagem "credenciais inválidas").
3. `03-cadastro.png` — criação de conta de cliente.
4. `04-lista-de-saloes.png` — lista de salões disponíveis.
5. `05-busca-de-saloes.png` — busca por nome ou endereço.
6. `06-detalhe-do-salao.png` — detalhe do salão com horários, datas indisponíveis e avaliações.
7. `07-escolher-data.png` — seleção da data do evento.
8. `08-escolher-horario.png` — seleção do horário.
9. `09-nova-reserva.png` — formulário de reserva preenchido.
10. `10-reserva-solicitada.png` — confirmação do pedido de reserva.
11. `11-minhas-reservas.png` — minhas reservas com os quatro status (pendente, aprovada, recusada, cancelada).
12. `12-atualiza-sozinho-pendente.png` — reserva recém-criada, ainda pendente.
13. `13-atualiza-sozinho-aprovada.png` — a mesma reserva já aprovada, atualizada sozinha pelo polling.
14. `14-cancelar-reserva.png` — confirmação de cancelamento.
15. `15-reserva-cancelada.png` — reserva cancelada.
16. `16-sair.png` — menu da conta com a opção de sair.
